# Python-Speech-Recognition-Voice Chatbot
A voice-controlled AI chatbot built using Python that can recognize voice commands, speak responses, open websites, perform calculations, search Wikipedia, check the weather, manage notes and to-do lists, set reminders, and execute basic system commands.

---

##  Features

- 🎤 Voice recognition using SpeechRecognition
- 🔊 Text-to-Speech using pyttsx3
- 🌐 Open websites (Google, YouTube, Wikipedia)
- 📚 Search Wikipedia
- 🕒 Tell the current time
- 📝 Save notes
- 📋 Manage To-Do List
- 🌦️ Get live weather information
- 🧮 Perform basic calculations
- ⏰ Set reminders
- 💻 Open desktop applications
  - Notepad
  - Calculator
  - Command Prompt
- ⚙️ System controls
  - Shutdown
  - Restart
  - Lock System
- 👋 Basic conversational responses

---

##  Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Requests
- Wikipedia API

##  Installation

Clone the repository

```bash
git clone https://github.com/yourusername/python-voice-chatbot.git
```

Move into the project directory

```bash
cd python-voice-chatbot
```

Install the required packages

```bash
pip install -r requirements.txt
```

Run the chatbot

```bash
python "python voice_chatbot.py"
```
